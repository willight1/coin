# 업비트 규칙 기반 자동매매 시스템

> **퀀트 트레이더 스타일** — AI는 전략 연구원, 실거래는 검증된 규칙만 실행

## 🎯 프로젝트 개요

이 프로젝트는 업비트 Open API를 이용한 **규칙 기반 자동매매 시스템**입니다.

### 왜 AI를 실시간 주문판단에 직접 쓰지 않는가?

| 항목 | AI 실시간 판단 | 규칙 기반 전략 |
|------|---------------|---------------|
| 재현성 | ❌ 같은 입력에 다른 결과 | ✅ 항상 동일한 결과 |
| 검증 가능성 | ❌ 백테스트 불가 | ✅ 과거 데이터로 검증 |
| 리스크 통제 | ❌ 예측 불가 | ✅ 명확한 규칙 |
| 디버깅 | ❌ 블랙박스 | ✅ 모든 로직 추적 가능 |
| 과최적화 방지 | ❌ 없음 | ✅ 검증 모듈로 방지 |

**결론**: AI는 전략 아이디어 생성, 파라미터 탐색, 리포트 해석 등 **연구 보조** 역할만 합니다. 실제 주문은 검증된 수식 기반 규칙으로만 실행됩니다.

## 🏗️ 시스템 구조

```
사용자/AI (전략 연구)
       │
       ▼
┌─────────────────────────────────────────────┐
│              전략 생성 영역                    │
│  strategies.py ← indicators.py               │
│  (수식 기반 규칙, 파라미터 조정)               │
└──────────────┬──────────────────────────────┘
               │ 전략 후보
               ▼
┌─────────────────────────────────────────────┐
│              검증 영역                        │
│  backtester.py → validator.py                │
│  (백테스트, 인샘플/아웃오브 분리, 과최적화 방지) │
└──────────────┬──────────────────────────────┘
               │ 검증 통과 전략
               ▼
┌─────────────────────────────────────────────┐
│              실거래 영역                      │
│  trader.py ← risk_manager.py                 │
│             ← upbit_client.py                │
│  (규칙 신호만 사용, DRY_RUN/LIVE 분리)        │
└─────────────────────────────────────────────┘
```

## 📁 파일 구조

```
trade/
├── config.py           # 환경변수 로드 & 설정 관리
├── logger.py           # 로깅 (콘솔 + 파일)
├── upbit_client.py     # 업비트 API 클라이언트
├── indicators.py       # 기술 지표 (RSI, SMA, EMA, MACD, ATR, BB 등)
├── strategies.py       # 5개 규칙 기반 전략
├── backtester.py       # 자체 백테스트 엔진
├── validator.py        # 전략 검증 (과최적화 방지)
├── risk_manager.py     # 리스크 관리
├── trader.py           # 실거래 엔진
├── main.py             # CLI 진입점
├── .env.example        # 환경변수 템플릿
├── requirements.txt    # Python 의존성
├── data/               # 시세 데이터 저장소
├── logs/               # 로그 파일
└── reports/            # 백테스트 결과 리포트
```

### 각 파일 설명

| 파일 | 역할 |
|------|------|
| `config.py` | `.env`에서 환경변수를 로드하여 dataclass 기반 설정 객체로 제공 |
| `logger.py` | 콘솔 + 날짜별 파일 로깅 설정 |
| `upbit_client.py` | JWT 인증, 시세 조회, 계좌 조회, 주문 실행 (DRY_RUN 차단, 재시도 로직) |
| `indicators.py` | RSI, SMA, EMA, MACD, ATR, Bollinger Bands 등 pandas 기반 지표 |
| `strategies.py` | 5개 전략 (RSI, 이동평균 크로스, RSI+MA, 볼린저, 돌파+거래량) |
| `backtester.py` | 수수료/슬리피지/손절/익절 반영 시뮬레이션, 성과 지표 계산 |
| `validator.py` | In/Out-of-sample 분리, 과최적화 탐지, 전략 순위 비교 |
| `risk_manager.py` | 매수 금액 제한, 잔고 유지, 포지션 제한, 쿨다운, 변동성 필터 |
| `trader.py` | 전략 신호 기반 자동 매매 (HOLD/BUY/SELL만 사용, AI 판단 없음) |
| `main.py` | CLI 진입점 — `backtest` / `validate` / `trade` 모드 |

## ⚙️ 설치 방법

### 1. 가상환경 생성

```bash
cd trade
python3 -m venv venv
source venv/bin/activate  # Mac/Linux
# venv\Scripts\activate   # Windows
```

### 2. 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열어서 실제 업비트 API 키를 입력하세요:

```env
UPBIT_ACCESS_KEY=실제_액세스_키
UPBIT_SECRET_KEY=실제_시크릿_키
UPBIT_MARKET=KRW-BTC
BOT_DRY_RUN=true          # 반드시 true로 시작!
```

> ⚠️ **API 키 발급**: 업비트 → 마이페이지 → Open API 관리 → API 키 발급

## 🚀 사용 방법

### 1단계: 백테스트

모든 전략을 과거 데이터로 시뮬레이션합니다.
API 키가 없어도 샘플 데이터로 실행 가능합니다.

```bash
python main.py --mode backtest
```

결과:
- 콘솔에 전략별 성과 요약 출력
- `reports/` 디렉토리에 CSV 파일 저장
  - 전략별 거래 로그
  - 전략 비교 리포트

### 2단계: 검증

백테스트 결과를 기반으로 검증 가능한 전략을 선정합니다.

```bash
python main.py --mode validate
```

검증 기준:
- 최소 거래 횟수
- MDD 제한
- 최소 승률
- Profit Factor 기준
- 손익비 균형 확인
- 과최적화 의심 경고

### 3단계: DRY_RUN 실행 (모의거래)

```bash
# .env에서 BOT_DRY_RUN=true 확인
python main.py --mode trade
python main.py --mode trade --strategy "RSI 과매도/과매수"
```

DRY_RUN 모드에서는 실제 주문이 실행되지 않고 로그만 기록됩니다.

### 4단계: LIVE 실행 (실거래)

```bash
# .env에서 설정 변경
BOT_DRY_RUN=false
```

```bash
python main.py --mode trade --strategy "RSI 과매도/과매수"
```

## ⚠️ LIVE 실행 전 체크리스트

1. ✅ 백테스트 결과 확인 (`reports/` 파일 검토)
2. ✅ 검증 통과 확인 (`--mode validate` 실행)
3. ✅ DRY_RUN 모드로 최소 24시간 이상 정상 동작 확인
4. ✅ `.env` 설정 확인:
   - `MAX_BUY_KRW` — 1회 최대 매수 금액 (작게 시작!)
   - `MIN_KRW_RESERVE` — 최소 잔고 유지
   - `STOP_LOSS_PCT` — 손절 퍼센트
   - `TAKE_PROFIT_PCT` — 익절 퍼센트
5. ✅ 업비트 API 키 권한 확인 (주문 권한 활성화)
6. ✅ 소액으로 시작 (최소 금액으로 1~2회 테스트)
7. ✅ 모니터링 체계 마련 (`logs/` 디렉토리 확인)

> 🚨 **경고**: 자동매매는 언제든 손실이 발생할 수 있습니다. 투자 원금 손실에 대한 책임은 사용자에게 있습니다.

## 🛡️ 리스크 관리

| 기능 | 설명 | 설정값 |
|------|------|--------|
| 1회 최대 매수 | 한 번에 투입하는 최대 금액 | `MAX_BUY_KRW` |
| 최소 잔고 유지 | 항상 유지할 최소 KRW | `MIN_KRW_RESERVE` |
| 최대 포지션 | 동시 보유 가능한 포지션 수 | `MAX_POSITIONS` |
| 손절 | 매수가 대비 하락 시 자동 매도 | `STOP_LOSS_PCT` |
| 익절 | 매수가 대비 상승 시 자동 매도 | `TAKE_PROFIT_PCT` |
| 쿨다운 | 주문 후 재주문까지 대기 | `COOLDOWN_SECONDS` |
| 변동성 필터 | ATR 과다 시 진입 차단 | 자동 (ATR × 2) |
| API 실패 | API 오류 시 모든 신규 주문 중단 | 자동 |
| 연속 진입 방지 | 동일 BUY 신호 3회 이상 연속 시 차단 | 자동 |

## 📊 전략 설명

### 1. RSI 과매도/과매수 전략
- **매수**: RSI(14) < 30 (과매도)
- **매도**: RSI(14) > 70 (과매수)
- **핵심**: 역추세 전략, 과열/냉각 포착

### 2. 이동평균 골든크로스/데드크로스 전략
- **매수**: SMA(5) > SMA(20) 상향 돌파 (골든크로스)
- **매도**: SMA(5) < SMA(20) 하향 돌파 (데드크로스)
- **핵심**: 추세 추종 전략

### 3. RSI + 이동평균 필터 전략
- **매수**: RSI < 30 AND 종가 > SMA(50) (상승 추세에서만)
- **매도**: RSI > 70 AND 종가 < SMA(50) (하락 추세에서만)
- **핵심**: 추세 방향에서만 RSI 신호 사용

### 4. 볼린저밴드 평균회귀 전략
- **매수**: 종가 < 볼린저 하단선 (반등 기대)
- **매도**: 종가 > 볼린저 상단선 (조정 기대)
- **핵심**: 평균 회귀, 밴드 폭 활용

### 5. 돌파 + 거래량 증가 전략
- **매수**: 20봉 최고가 돌파 AND 거래량 > 평균 × 1.5
- **매도**: 종가 < SMA(10) (추세 이탈)
- **핵심**: 강한 모멘텀 돌파 포착

## 🤖 AI 확장 가능 지점

AI를 이 시스템에 연결할 수 있는 지점은 다음과 같습니다.
**단, AI는 절대로 실시간 주문 판단에 직접 사용하지 않습니다.**

### 1. 전략 아이디어 생성
AI에게 "어떤 지표 조합이 현재 시장에 적합한가?"를 물어볼 수 있습니다.
생성된 아이디어는 `strategies.py`에 새로운 클래스로 직접 구현합니다.

```python
# AI가 제안한 아이디어 → 개발자가 구현
class AIGeneratedStrategy(BaseStrategy):
    """AI 제안: RSI + MACD + 볼린저 3중 필터"""
    ...
```

### 2. 파라미터 후보 생성
AI에게 "RSI 기간을 10~20 중 어떤 값이 좋을지"를 물어보고,
후보 파라미터로 백테스트를 반복 실행할 수 있습니다.

### 3. 백테스트 결과 요약
AI에게 `reports/` 디렉토리의 CSV 결과를 분석하게 하여,
"어떤 전략이 어떤 시장 상황에서 좋았는지" 요약을 받을 수 있습니다.

### 4. 리스크 리포트 해석
AI에게 MDD, 승률, Profit Factor 등의 지표를 해석하게 하여,
"이 전략의 위험 수준이 어느 정도인지" 설명을 받을 수 있습니다.

### 5. 시장 상태 분류 보조
AI에게 "현재 시장이 추세장인지 횡보장인지" 분류를 요청하고,
그 결과를 참고하여 **수동으로** 전략을 교체할 수 있습니다.
(자동 교체 아님, 참고 자료로만 활용)
