# 전략 연구 기록

## 측정된 사실 (2026-09-30, KRW-BTC, 20,000봉)

현재 규칙 전략 7개는 **비용을 넘는 엣지가 없다.** 다시 재보기 전에 알고 시작할 것:

| | 1분봉 (14일) | 15분봉 (208일) |
|---|---|---|
| 단순 보유 | +8.42% | +7.07% |
| 최고 전략 | +1.46% | **−3.50%** |
| 최악 전략 | −0.19% | **−13.13%** |
| Profit Factor | 0.90~2.51 | **전부 1 미만** |

1분봉이 나아 보이는 건 실력이 아니라 거래가 적어서(14일에 15~31회)다. 15분봉에서 거래가 10배로 늘자 승률이 86%→56%로 떨어지고 PF가 전부 1 아래로 내려갔다.
리스크 파라미터 336개 조합을 스윕해도 아웃오브샘플 양수 조합은 거래 2회짜리(통계적 무의미)뿐이었다.

**파라미터 튜닝으로 해결되는 문제가 아니다.** 전략 자체나 시장/상품을 다시 봐야 한다.

### 비용 0 진단 (2026-09-30, KRW-BTC, 20,000봉, `--mode validate`)

"비용 때문에 지는가, 비용이 없어도 지는가"를 가르려고 `FEE_RATE=0 SLIPPAGE_RATE=0`으로 다시 쟀다. 표의 값은 아웃오브샘플 PF 범위다(거래 0회인 RSI+MA 필터는 제외).

| 봉 | OOS 구간 | 단순 보유 | 실비용 OOS PF | 비용 0 OOS PF |
|---|---|---|---|---|
| 15분 | 2개월 | +23% | 0.66~1.53 | 0.99~2.31 |
| 60분 | 8개월 | −16% | 0.52~0.75 | 0.70~1.02 |
| 240분 | 2.7년 | **+90%** | 0.43~0.91 | 0.54~1.10 |

- 긴 봉(60/240)에서는 **비용이 0이어도 PF가 1 안팎이다.** 비용을 줄이거나 봉을 늘리는 것으로는 풀리지 않고, 지표 자체에 예측력이 없다.
- 15분봉은 비용 0일 때 PF가 1을 넘지만, OOS가 2개월짜리 강세장이고 보유(+23%)에 크게 진다.
- 240분 비용 0에서 "돌파 + 거래량 증가"가 통과했지만 +1.86%(보유 +90%)이고, 실비용에서는 탈락한다. 근거로 쓰지 말 것.
- 60분 하락 구간(보유 −16%)에서는 전략들이 보유보다 덜 잃었다(−0.4~−9%). 전략이 보여준 쓸모는 이것(하락 방어)뿐이다.
- "RSI + 이동평균 필터"는 모든 설정에서 거래가 0회다. 조건이 한 번도 성립하지 않는 죽은 전략이다.
### 일봉 추세 필터 (2026-09-30, 종가 > SMA N이면 보유, 아니면 현금)

`Backtester`와 `RiskManager`를 그대로 쓰되 손절·트레일링·순이익 게이트·ATR 차단을 끄고 전액을 투입했다. OOS는 2024-01~2026-09이고, SMA는 전체 이력으로 미리 계산했다(구간을 잘라 계산하면 SMA200이 OOS의 처음 200일을 날린다).

| OOS | 전략 수익 / MDD | 보유 수익 / MDD | 매수 횟수 |
|---|---|---|---|
| BTC SMA50 / 100 / 200 | +183 / +123 / +99%, MDD 26~34% | +93%, MDD 50% | 연 4~10회 |
| ETH SMA50 / 100 / 200 | +116 / +80 / +82%, MDD 30~48% | +2%, MDD 64% | 연 3~9회 |

- 두 코인, 세 기간 모두 OOS에서 보유 대비 MDD가 낮고 수익은 같거나 높았다. 처음으로 비용을 넘는 엣지가 확인된 구조다.
- 한계: OOS 구간이 하나뿐이고, 승률이 30~50%다. 보유 기간 중앙값은 4~6일(잦은 휩쏘)이고, 수익은 몇 번의 긴 보유(최장 391~432일)에서 나온다. MDD도 여전히 26~48%다.
- 위 표는 TREND_EXIT를 신호 다음 봉 **종가**에 체결하던 시절에 잰 값이다(매도가 하루 늦음). 이후 **다음 봉 시가**로 고쳤다. 트레이더는 새 봉이 열리자마자 팔기 때문이다.
- 봇 편입: `SmaTrendStrategy(50)`, `BOT_CANDLE_UNIT=1440`(일봉). 전략이 `risk_overrides`로 전액 투입과 손절·트레일링 끄기를 들고 다닌다. 기본 리스크값(15분봉용)으로 돌리면 추세 중간에 털려서 다른 전략이 된다.
- SMA200을 못 쓰는 이유: 트레이더는 200봉만 받으므로 period는 200 미만이어야 한다.
- `--mode validate` 결과 (시가 체결 반영): BTC OOS +85.7%, ETH OOS +87.1%(OOS PF 2.9 / 2.6)이지만 **탈락**이다. 인샘플 MDD 56%(2018 폭락 구간) > 기준 30%, 승률 27% < 기준 30%. 기준을 완화하지 말고, MDD를 줄이는 쪽으로 풀 것.
- MDD 줄이기 측정 (시가 체결, 2017-09~): **BTC/ETH 반반 분산은 효과가 없다**(MDD 56%→54%, 두 코인이 같이 빠짐). **투자 비중 50%**로 줄이면 MDD가 56%→40%로 내려가고 연수익은 +76%→+48%가 된다. SMA100은 SMA50보다 수익과 MDD 모두 나빴다.
- 하락장 (BTC, SMA50, 비중 100%): 2018년 보유 −78% → 전략 −29%, 2022년 −63% → −44%, 2025년 −8% → +18%, 2026년(~9월) −12% → +6%. **큰 하락장에서는 손실을 줄일 뿐 여전히 잃는다.** 현물 롱 전용이라 하락으로 돈을 벌 수는 없다. 2022년이 약한 이유는 하락 중 반등마다 샀다가 털렸기 때문이다(휩쏘).
- 비중은 `TREND_BUY_RATIO_PCT`(기본 1.0)로 조절한다. 전역 `BUY_RATIO_PCT`(0.30)는 추세 전략에 적용되지 않는다. `.env.example`을 그대로 복사하면 추세 전략이 30%로 조용히 돌기 때문에 일부러 분리했다. 멀티마켓(`UPBIT_MARKETS`)은 트레이더들이 KRW 잔고를 공유하므로, 비중 100%면 먼저 신호가 난 마켓이 전액을 가져간다.

- 실험할 때 주의: zsh는 `E="A=0 B=0"; env $E ...`를 단어로 쪼개지 않는다. 변수를 직접 적을 것.

### 추세 전략 변형·코인 확장 (2026-10-01)

- **SMA50 개선안** (BTC·ETH·XRP, 2018-06~, 기간 3등분): 20~50일 짧은 추세추종은 3개 코인 모두에서 9개 구간 중 8개에서 보유보다 나았다. 100·150·200일 SMA, 골든크로스, 90일 모멘텀은 약했다(XRP에서는 손실). 상위권(SMA20, SMA50, SMA50+기울기 필터, 변동성 목표) 사이의 순위는 코인과 시작 시점에 따라 뒤바뀐다 → 오차 범위.
- **기울기 필터**(SMA50이 N일 전보다 높을 때만 매수): N=1~20 어느 값이든 2022년 손실을 줄였다(−44% → −18~−34%). 대신 2023년 급반등 수익과 9년 총수익은 모든 N에서 줄었다. 개선이 아니라 득실 교환이다.
- **휩쏘를 줄이려는 시도**(매도 버퍼 2%, 2일 연속 확인, +2% 위에서 매수)는 전부 나빴다. 폭락장에서 늦게 빠져나오기 때문이다.
- **장중 평균선 돌파 즉시 매매**: 종가 확정 후 매매보다 나빴다(9년 +3,922% vs +6,622%, OOS +64% vs +180%). 같은 날 샀다 판 날이 147일, 매매는 연 30회.
- **코인 전체로 확장** (KRW 257개, 2022-11~, 알트 비용 편도 0.2%, 현재 상장만이라 생존 편향 있음):
  - BTC 단독 SMA50: 연 +59%, MDD 23% (최고)
  - BTC+ETH 반반: 연 +57%, MDD 27%
  - BTC 50% + 알트 분산 50%: 연 +33%, MDD 38%
  - 전 코인 분산: 연 +10%, MDD 64%
  - 모멘텀 상위 5개 로테이션: −96%
  - 알트는 SMA50이 보유보다 나은 코인이 92%지만, 수익 중앙값은 −13%다(보유 중앙값 −75%).

### 장중 매도 장치 추가 연구 (2026-10-03) — 전부 개선 없음

SMA50 일봉 추세(BTC·ETH·XRP 9년, 2018~)에 장중 즉시 매도 장치를 얹어 비교했다. 장중 체결은 하루 저가로 판정했고, 긴급 매도·재매수 비용은 편도 0.2%로 잡았다.

| BTC | 연수익 | MDD | OOS(2024~) |
|---|---|---|---|
| 현재 (종가 이탈 → 다음 날 09시 매도) | **+62%** | 56% | **+180%** |
| 긴급 매도: 기준선 −0/3/5/7/10% 장중 이탈 | +52~55% | 60~63% | +58~123% |
| 트레일링: 보유 중 최고가 −5/10/15/20% | +42~55% | 49~68% | +74~146% |
| 고정 손절: 매수가 −5/10/15% | +61~62% | 54~57% | +163~180% (거의 미발동) |
| 긴급 −5% / 트레일링 −10% + 3·5% 반등 시 장중 재매수 | +47~54% | 56~62% | +94~123% |

- 셋 중 어떤 장치도 **수익과 MDD를 동시에 개선하지 못했다.** 긴급 매도는 MDD마저 커졌다. 장중 바닥에서 판 뒤, 평균선 위로 마감한 다음 날에야 다시 사서 더 비싸게 사게 되기 때문이다.
- 트레일링은 상승 중의 10~20% 출렁임에 걸려 큰 추세를 놓친다. BTC 2021년이 +220%에서 +100~200%로 줄었다. ETH·XRP에서도 수익이 크게 줄었다.
- 고정 손절은 BTC에서 9년간 1~2회만 발동해 결과가 같았고, ETH에서는 OOS가 +168%에서 +62~79%로 줄었다.
- 반등 재매수는 거의 발동하지 않았다(스탑 10회 중 3~6회). 스탑이 걸린 날은 대부분 진짜 하락의 시작이었다.
- **결론: 매도 규칙은 지금처럼 '종가 이탈 → 다음 날 09시 매도' 하나로 둔다.** 장중 상황은 매매가 아니라 알림(`_check_intraday_warning`, `TREND_WARN_PCT`)으로만 알린다.

### 수익 구간 매도 연구 (2026-10-18) — 전부 개선 없음

계기: 10/3 BTC 매수 → +2.7%까지 올랐다가 평균선 이탈로 −3.4% 매도. "수익 났을 때 팔자"를 SMA50 일봉(BTC·ETH·XRP, 2017-09~2026-10, OOS 2024~)에 얹어 쟀다. 재진입은 wait(평균선 아래로 갔다 다시 올라올 때만) / next(다음 날도 평균선 위면 시가 재매수) 두 가지.

| BTC | 연수익 | MDD | OOS |
|---|---|---|---|
| 현재 | **+75%** | 56% | +166% |
| 본전 보호: +3/5/10/20% 찍은 뒤 매수가+0.2%로 돌아오면 장중 매도 | +29~74% | 47~59% | +75~173% |
| 고정 익절: +3/5/10/20/50% 장중 지정가 매도 | −1~+69% | 22~60% | +14~169% |

- 승률은 오른다(30% → 50~80%). 그런데 연수익은 같거나 줄었다. 손익 대부분이 몇 번의 긴 추세에서 나오는데, 익절이나 본전 보호가 그 추세를 잘라낸다.
- ETH는 모든 조합에서 연수익이 현재(+95%)보다 낮았다. XRP는 본전 보호(wait)가 OOS +222~276%로 높았지만 전체 기간 연수익은 +52% → +14%였다. 한 구간에서만 좋아 근거가 못 된다.
- 고정 익절 wait는 MDD가 22~45%로 낮지만, 수익도 보유 시간에 비례해 줄어든 결과다. 연수익 0~13%라 비중을 줄이는 것(50% 비중: MDD 40%, 연 +48%)보다 못하다.
- 스크립트는 scratchpad에 둔 1회성(일봉 OHLC, 장중 체결은 고가·저가로 판정, 본전 보호 체결 비용은 편도 0.2%, 익절은 지정가라 0.1%).

**기준선 즉시 매매 (2026-10-19) — 개선 없음.** 종가 확정을 기다리지 않고 현재가가 기준선(직전 49종가 평균)을 넘으면 바로 매수, 깨면 바로 매도. 1시간봉 종가로 판정하고 다음 시간 시가에 체결했다(2017-09~, 편도 0.1%).

| | BTC 연수익 / MDD / OOS | ETH 연수익 / MDD / OOS |
|---|---|---|
| 현재 (일봉 종가 → 다음 날 09시) | **+75% / 56% / +166%** | **+95% / 60% / +183%** |
| 즉시, 완충 없음 (거래 361·381회, 승률 12%) | +65% / 65% / +73% | +74% / 69% / +75% |
| 즉시, 완충 ±0.5~2% | +73~74% / 63~64% / +139~195% | +84~91% / 68~71% / +152~159% |

- 기준선 근처에서 하루에도 여러 번 넘나들어 휩쏘가 폭증한다. 완충폭을 넣으면 수익은 현재 수준으로 돌아오지만 MDD는 항상 더 크다.
**일봉 완충폭 (2026-10-19) — 엇갈림, 미채택.** 평균선 근처 휩쏘(하루 만에 사고팔기) 대책으로 "종가가 SMA50×(1+a) 위면 매수, ×(1−b) 아래면 매도"를 쟀다.

| | BTC 연수익 / MDD / OOS | ETH | XRP |
|---|---|---|---|
| 현재 (0/0) | +75% / 56% / +166% | +95% / 60% / +183% | +52% / 83% / +208% |
| +1% / −1% | +77% / 57% / +215% | +99% / 63% / +222% | +45% / 82% / +108% |
| +1~3% / 0 (매수만 완충) | +70~74% / 51~57% / +93~146% | +90~93% / 58~62% / +96~119% | +50~52% / 82~83% / +163~175% |
| ±2~3% | +55~58% / 66~69% | +87~93% / 58% | +42~46% / 75~80% |

- 2일 안에 되파는 거래는 확실히 준다(BTC 23 → 5회). 그런데 수익은 ±1%만 BTC·ETH에서 소폭 좋아졌고, XRP는 나빠졌다. MDD는 개선되지 않았다.
- 7개 중 결과를 보고 고른 1개가 소폭 나은 수준이라 근거가 약하다. 휩쏘 손실은 큰 추세를 놓치지 않는 대가로 받아들인다.

- **함정:** 일봉 OHLC로만 재면 "하루 한 번, 기준선 가격에 정확히 체결"을 가정하게 돼 BTC 연 +122%, MDD 36%처럼 크게 좋아 보인다. 장중 규칙은 반드시 시간봉 이하로 검증할 것.

### 횡보장 역추세 연구 (2026-10-22) — 전부 탈락

"추세 전략의 횡보 손실을 뒤집으면 횡보 수익" 가설. 일봉 2017-09~2026-10, 종가 신호 → 다음 날 시가, 편도 0.1%.

| 전략 | BTC 전체 / MDD / OOS24~ | ETH 전체 / OOS | XRP 전체 / OOS |
|---|---|---|---|
| 추세 (종가>SMA50, 현재) | +16199% / 56% / +174% | +43175% / +188% | +4218% / +208% |
| 반대 (종가<SMA50이면 보유) | −93% / 94% / −36% | −98% / −66% | −88% / −36% |
| 눌림 SMA−3/5/10% 매수 → 선 복귀 매도 | −84 / −75 / −75% | −98 / −97 / −95% | −81 / −84 / −76% |
